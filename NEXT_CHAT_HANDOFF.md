## Что сделать в НАЧАЛЕ нового чата (обязательно)

1. Прочитать (в этом порядке):
   `NEXT_CHAT_HANDOFF.md` (этот файл) → `DEVLOG.md` (верхняя запись) →
   `ROADMAP.md` (блок «Текущий статус» и «Дальше») →

   `scripts/assets/README.md`; QA — `scripts/qa/README.md`.
2. Подготовить окружение:
   `corepack pnpm install` (если нет `node_modules`), затем зелёный контур:
   `pnpm run typecheck`, `pnpm --filter @workspace/my-app run test:pillars`,
   `pnpm --filter @workspace/my-app run validate:catalog`,
   `pnpm --filter @workspace/my-app run build`.
   QA-браузер (один раз на песочницу): `node scripts/qa/setup-browser.mjs`
   (Chromium `@sparticuz/chromium@131.0.1` + `puppeteer-core@23.11.1`, не Playwright).
3. Понять, **на чём остановились** и что нельзя трогать. После — **ждать
   указания владельца**; ничего нового не начинать самому.

## Канон сейчас (не нарушать)

- Единственная профессия — **«Сбор»** (`SkillId = 'foraging'`, 5 зон).
  Характеристики — **четыре столпа** (Стойкость/Мощь/Сноровка/Чутьё),
  12 ветвей, нити, пассивки. Легаси-навыки не возвращать.
- Предметы — **только каталог** `src/domain/items/catalog/` (630 шт.);
  вход — `src/domain/items/index.ts` (`getItem()`/`getAllItems()`).
  Легаси-эмодзи (`items.ts`) — только для чтения старых сейвов.
- Числа — только `src/data/balance/`. Тиры снаряжения 1–12 — генерация
  `база тира 1 × gearTierScale(tier)` в `data/balance/gear.ts`
  (`GEAR_TIERS_NOW = ALL_GEAR_TIERS`). Уники — флаг `gearUnique`, не тир.
- Картинки — только WebP через `iconUrl()` / `getAvatarPath()`;
  `.png` в `<img>` запрещён. Конвейер: `scripts/assets/README.md`.
- Вывеска греет первый кадр, каталог НЕ качает (`lib/bootPreload.ts` не трогать).
- **Банк** — будущая отдельная система, сейчас не существует: инвентарь — это
  «сумка» (`/inventory`). Терминологический закон: `BANK_FOUNDATION.md`.
- Тексты игроку — `ruleRu`. Неподключённое честно помечаем «не действует».
- XP-таблица (`data/balance/xpRates.ts`) и боевые пассивки **не подключены**
  к тикам — не подключать «чтобы было».

## Следующая работа (только по слову владельца)

**Стратегическое направление (утверждено владельцем 2026-09-10):**
этап **UI/UX-унификации** идёт по канону **«Стекло таверны»** — эталон
«Ложа таверны» (создание персонажа): живописный фон + матовое стекло

Все рецепты, решения №1–6 и план — в **`UI_UX_AUDIT.md`** (разделы 0, 4–7).
**Прогресс плана §6:** шаги 1–9 реализованы и приняты владельцем; эмблема
уникальности выбрана — золотая звезда (`UniqueEmblem`), фон слоя 0 — одна
общая картина; легаси-предметы удалены (шаг 7). Шаг 9а — «рамка один
экран» (полная мобильная адаптация по блокеру владельца): шелл `100dvh`
без прокрутки страницы, окно прокрутки `.app-main`, паттерн `.a-page`,

добивка по скриншотам владельца: рейл админки и вкладки хаба выровнены
на всю ширину (продолжение 15 DEVLOG).
**Шаг №10 ПРИНЯТ владельцем целиком (2026-09-11):** нижняя навигация
переписана — стеклянная панель слоя 1 + шесть пунктов (Город / Бой /

(мастера PNG + webp 256 в `public/assets/icons/menu/`). Поведения:
