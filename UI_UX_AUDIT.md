# UI/UX-аудит окон — фактура и канон «Стекло таверны»

> **Статус: НАПРАВЛЕНИЕ УТВЕРЖДЕНО владельцем 2026-09-10 (Сессия 31).**
> Аудит (§1–3) — запись фактов. Канон и план (§4–7) переписаны по ответам
> владельца: **уходим от слишком тёмного стиля** к концепции «Ложа таверны» —
> живописный фон + матовое стекло + тёплые какао-карточки + золото.
> Код пишем по плану §6, один шаг за раз.

**Область:** навык «Сбор», интерфейс персонажа (`/hero`: Тело/Экип/Нити/Путь),
админ-панель, инвентарь, мелкие окна (модальные окна, всплывающие карточки,
тосты). Вне области: бой, удалённые навыки, лендинг/главный экран-панель
(дожидаются своей очереди).

**Метод:** скан кода (шестнадцатеричные коды цвета, переменные, примитивы,
классы) + живые скриншоты на локальном пробном режиме (телефон 390×844,
компьютер 1280×820; команды в приложении А).

## 0. Эталон глазами владельца

Владелец отобрал два экрана, которые «радуют глаз», как образец для всей игры:

1. **«Ложа таверны»** (создание персонажа, шаг «Наследие») и
2. **«У порога таверны»** (выбор персонажа).

Что их объединяет (это и есть будущий канон):

| Элемент | Рецепт эталона (уже лежит в коде!) |
|---|---|
| Фон | Нарисованная картина на весь экран (`character_creation_lodge.webp`, `auth_tavern_background.webp`), затемнённая |
| Панель | **Матовое стекло:** `--onboarding-panel` = градиент `rgba(49,31,19,0.64) → rgba(16,10,6,0.76)`, `backdrop-filter: blur(0.65rem) saturate(1.04)`, радиус 1.4rem, тень `0 1.25rem 3.5rem rgba(0,0,0,0.46)` + внутренний блик `inset 0 1px 0 rgba(255,235,190,0.10)`, край `rgba(224,168,70,0.36)` |
| Карточки внутри | Тёплые какао-градиенты `GCard` из `gameUI`: `linear-gradient(160deg,#7a5028,#5a3818)`, край `#5a3010`, выбранная — золотой край `#c8880a` + свечение |
| Текст | Крем `--cinematic-light: rgba(255,237,196,0.94)`, приглушённый `--cinematic-copy: rgba(237,213,165,0.86)`, золото `--cinematic-gold: rgba(245,195,92,0.96)` |
| Кнопка-главная | Янтарный градиент (один вид на всё приложение!) |
| Выбор | Золотое кольцо + золотой край карточки (не цветовые коды) |

**Радостное обстоятельство:** эталон собран на уже существующих переменных
`--cinematic-*` / `--onboarding-*` и примитивах `gameUI`. Значит концепцию не
нужно «изобретать» — нужно **поднять эти рецепты в глобальную тему** и стереть
конкурирующие диалекты.

## 2. Наблюдение: игра — не «чёрное пятно», но хочет им быть

Владелец: «слишком тёмный стиль, на телефоне выглядит как чёрное пятно».
По скриншотам видно почему: игровые экраны (гость/инвентарь/админка/«Сбор»)
собраны из **плоских почти чёрных заливок** без фона — на маленьком экране
сливаются в тёмную масу. Эталонные экраны стоят на **картине под стеклом**:
глубина появляется бесплатно, панели читаются как тёплое стекло, а не как ямка.

Админка и хаб героя уже самопроизвольно собрались в схему «тёмный каркас →
лист → карточки → ячейки», но без фона-картины и без стекла, плюс нарушения
(см. §3). Концепцию не меняем дугой — **переводим все окна на рецепт эталона**.

## 3. Аудит по окнам (факты со скриншотов и кода)

### 3.1. Интерфейс персонажа `/hero`

- Хорошо: шапка героя, вкладки, доска «Тело», «Нити», «Путь» — единый язык внутри себя.
- **«Экип» смешивает два поколения ячеек в одном окне** (старые тёмные
  `.hero-sq-slot` с серыми силуэтами рядом с новыми светлыми `ItemCell`).
- Модальное окно столпа: подписи строк почти не читаются (тёмный серый текст
  на средне-коричневом) — баг контраста.
- Модальные окна хаба — вторая реализация окон рядом с `GModal`.

### 3.2. «Сбор»

- Карточки зон цельные и понятные; запертые приглушены правильно.
- Файл-рекордсмен: 71 вручную написанный код цвета (пилюли процентов,
  замок уровня, иконка-подсказка, строки статистики).
- Шапка профессии — средне-коричневая, не совпадает с шапкой героя.
- Место под иконку зоны сейчас пустой тёмный кадр (арт не привязан).

### 3.3. Инвентарь

- Сетка ровная, `ItemCell` — единый рендер заполненных ячеек.
- «Шахматка»: заполненные ячейки светлые, пустые — тёмные (шум);
  **решение владельца №6:** пустые делаем приглушёнными светлыми (стекло).
- Плашка «УНИК» висит за краем ячейки — **удаляется** (см. решение №3).
- Всплывающее окно предмета — почти чёрное со своими цветами пилюль и ярко-оранжевой кнопкой.
- **Старые предметы с английскими именами** («Bronze Sword») среди русского каталога — **удаляются все** (решение №5).

### 3.4. Админ-панель

- Три системы вкладок сразу; «лист» на телефоне пергаментный, на компьютере тёмный — расхождение.
- Кнопки «Сохранить»/«Выдать» — максимально яркий жёлтый (4-й диалект кнопки).
- Тост «Прогресс сохранён» перекрывает кнопку «Сохранить» в шапке на компьютере.

### 3.5. Мелкие окна и каркас

- `GModal` принят в 8 местах — хорошая база; `UniversalInfoModal` — отдельная реализация рядом.
- Нижняя навигация: жёсткая раскраска активной вкладки по разделам
  (янтарь/рубин/изумруд/небесный) — **по решению №2 вся навигация ждёт
  большую переделку с рисованными иконками**, до того не трогаем.
- Тост — коллизия с шапкой (см. 3.4).

## 4. Решения владельца (2026-09-10)

| № | Вопрос из аудита | Решение владельца |
|---|---|---|
| 1 | Тёмная или светлая тема? | **Ни та, ни другая в чистом виде: канон = «Ложа таверны».** Живописный фон + заблюренное матовое стекло + тёплые какао-карточки + золото. От плоского тёмного стиля уходим («чёрное пятно» на телефоне). Заблюренный фон оставить и развить — «игра выглядит глубже и живее». |
| 2 | Цветокод разделов в нижней навигации? | Вопрос снят: **нижняя навигация целиком будет переделана** отдельным шагом — под общий стиль, со сгенерированными иконками. До этого момента каркас не трогаем. |
| 3 | Бейдж тира за краем ячейки? | Числовой бейдж тира (Т1–Т12) — оставить, он «выглядит неплохо». **Плашку «УНИК» — убрать.** Уникальность показываем маленьким золотым знаком-эмблемой (фавиконом). Кандидаты нарисованы (корона ✦ звезда ✦ самоцвет), выбор — за владельцем. |
| 4 | Каталог примитивов? | **Основа — `kit`** (нравится формат: жидкое стекло, минимализм, идеальные размеры, общий стиль). От него берём дисциплину и отталкиваемся от его изысканности. Цветовую душу (какао-карточки) переносим из `gameUI`. |
| 5 | Старые предметы с английскими именами? | **Убрать все, однозначно.** В игре живёт только новый каталог (картинки, описание, цена, свои характеристики). Отдельный шаг: удаление старых определений + бережная очистка старых сейвов. |
| 6 | Пустые ячейки? | На усмотрение агента. **Решаю:** пустые — приглушённое матовое стекло (тот же рецепт панели, прозрачнее), заполненные — светлый картон. Шахматка исчезает. |

## 5. Канон «Стекло таверны» (свод для всех будущих окон)

### 5.1. Пять слоёв (закон, а не руководство)

| Слой | Назначение | Рецепт |
|---|---|---|
| **0. Картина** | Фон приложения/окна, настоящее живописное арт-полотно, затемнённое + слегка размытое | сначала одна общая картина на всё приложение (из уже лежащих в игре `auth_tavern_background.webp` / `character_creation_lodge.webp`); потом — разные по разделам (следующий художественный этап) |
| **1. Стекло** | Каркас (шапки, нижняя навигация после переделки), листы окон, фильтры-панели | `--onboarding-panel` + `blur(0.65rem) saturate(1.04)` + край `rgba(224,168,70,0.36)` |
| **2. Карточка** | Контент-блоки внутри листа | какао-градиент `#7a5028 → #5a3818`, край `#5a3010`; выбранная — золотой край `#c8880a` + свечение |
| **3. Ячейка** | Слоты предметов | заполненная — светлый картон с рамкой; пустая — матовое стекло (слой 1, прозрачнее) |
| **4. Краски** | Текст/иконки/метки | крем `rgba(255,237,196,0.94)`, приглушённый `rgba(237,213,165,0.86)`, золото `rgba(245,195,92,0.96)`, одна янтарная главная кнопка |

### 5.2. Запреты (с момента утверждения)

- Плоские почти чёрные заливки как основа экрана — вне закона.
- Дефолтные цвета tailwind вне шкалы (`amber-500`, `emerald-600`, `#4ade80`,
  `#60a5fa`, `#1a2538`) — заменяются на шкалу таверны.
- Вторая насыщенность янтаря для главной кнопки — одна на всех.
- Надпись «УНИК» любой плашкой — только эмблема-знак (после выбора владельца).

### 5.3. Шкалы

- **Скругления:** 8 (метки) / 12 (ячейки, поля) / 14 (карточки — из `gameUI`) /
  22 (окна и листы — из эталона, 1.4rem) / круглые (яйца-плашки).
- **Тень карточки/стекла** — из `--onboarding-panel-shadow` (глубокая + внутренний блик).
- **Прозрачность стекла:** панель `blur(0.65rem)`; пустая ячейка — тот же
  рецепт с большей прозрачностью; затемнение модальных окон — blur уже есть.

### 5.4. Примитивы (целевой набор, базируется на `kit`)

Один компонент на задачу; `kit` дополняется рецептами §5.1, `gameUI` становится
источником цветов и постепенно сливается внутрь. Состав тот же, что в первой
версии аудита: `AWindow / ASheet / ACard / ACell / ATabs / AButton / ABadge /
ADot / AField / AProgress / AToast` + **новый `ABackdrop`** (картина слоя 0,
одна точка подключения, чтобы фон было легко менять).
