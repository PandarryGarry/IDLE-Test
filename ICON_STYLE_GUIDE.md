# Стиль иконок Aethelia — закон и рецепт генерации

> Статус: утверждён владельцем 2026-09-11 (стиль пробников нижней навигации).
> Действует для всех будущих иконок интерфейса: меню, кнопки, слоты, бейджи-рисунки.
> Иконки предметов каталога уже живут в этом стиле — этот документ фиксирует его
> как закон и даёт повторяемый рецепт.

## 1. Суть стиля (пять правил)

1. **Плоский тёплый рисунок** (flat / semi-flat): формы простые и смелые,
   тени мягкие пятнами, никакой фотореалистичности и «эпичных блёсток»
   (эпичная живопись — это стиль артов дороги, НЕ иконок).
2. **Палитра какао и золото.** Основные тона — с сайта (`src/index.css`):

   | Роль | Цвет |
   |---|---|
   | Золото линий/металла | `#f0c030` (мягкий вариант в артах: `#f5c35c`) |
   | Какао-основа | `#6b4a2f` … `#8a5a30` |
   | Глубокое какао | `#4a2f1c`, `#3a1e08`, `#5a3010` |
   | Крем (пергамент, стежки) | `#efe0c0`, `#fff8d0` |
   | Янтарный свет (окна, блики) | `#f0b35c`, `rgba(245,195,92,0.96)` |
   | Тёмный фон-полотно | `#1c1006` … `#0d0603` |

3. **Без текста и букв** — генератор искажает надписи (исключение: знак
   тира `T1…T12` и цифры — но их рисует код поверх, не арт).
4. **Один предмет на иконку**, силуэт читается в 24–32 пикселя в высоту.
   Щедрый отступ от краёв (~12–15% холста).
5. **Холодные «стальные» и синие тона — чужеродны.** Старые `menu_profile`
   (синий капюшон) и `menu_battle` (стальные мечи) — анти-пример из наследия.

## 2. Эталоны (держать перед глазами и подавать генератору как референсы)

- `public/assets/icons/ui/emblem_axe_quill.webp` — герб «топор и перо»;
- `public/assets/icons/armor/cloth/t03/chest.webp` — тканая куртка;
- `public/assets/icons/menu/menu_inventory.webp` — рюкзак (тёплая часть наследия);
- серия нижней навигации 2026-09-11 (`nav3-city`, `nav4-arena`, `nav4-world`,
  `nav4-quests`, `nav3-inventory`, `nav3-settings` — мастера примятия см. в
  `public/assets/icons/menu/` после одобрения владельца).

## 3. Шаблон промпта (английский, проверен на серии навигации)

```
Draw ONE new game menu icon in EXACTLY the same flat stylized style as the
three reference icons: flat shapes, warm brown-and-gold palette, soft rounded
silhouettes, minimal detail, no realism. Subject: <ПРЕДМЕТ ОДНИМ ПРЕДЛОЖЕНИЕМ>
— the "<НАЗНАЧЕНИЕ>" icon for a fantasy RPG. Warm cocoa-brown, golden accents.
PURE BLACK background filling the whole canvas edges, centered, square 1024
icon, generous margin. No text, no letters, no characters anywhere.
```

Правила работы с генератором:
- обязательно прикладывать 2–3 эталона из §2 как reference images;
- один предмет за вызов; проверять глазами: дубли деталей (два компаса),
  буквы, фотореализм — сразу перегенерировать;
- фон просить строго чёрный (для последующего снятия); белый фон на
  светлых предметах (пергамент) допустим — снимается flood-fill с краёв.

## 4. Технический процесс внедрения

1. Кандидаты идут на одобрение **владельца** — до этого в игру ничего
   не попадает (правило 2026-09-11).
2. Одобренный кандидат: снять фон (пример для чёрного фона):
   `convert in.png -fuzz 6% -fill none -draw 'alpha 8,8 floodfill' -draw 'alpha 1015,1015 floodfill' out.png`
   повторить из всех углов; проверить края глазами.
3. Мастер PNG 1024×1024 с прозрачностью → `public/assets/icons/<группа>/<имя>.png`.
4. `node scripts/assets/optimize.mjs` — рядом появится рабочий `.webp`.
5. В коде — только `iconUrl('<группа>/<имя>')`; **сырой `.png` в разметке
   запрещён** (закон из `scripts/assets/README.md`).

## 5. Анти-примеры (так НЕ делать)

- Реалистичная 3D-закраска с бликами и мелкой текстурой — это стиль артов
  дороги/кутсцен, не иконок.
- Гравюрная штриховка монохромом («дорогая книга») — красиво, но не наш язык.
- Синие, стальные, пурпурно-неоновые тона.
- Буквы и слова в арте (текст — только кодом поверх).
