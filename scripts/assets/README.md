# Картинки Aethelia — конвейер (закон)

Не конвертировать файлы вручную «на один экран». Любая новая картинка
(предмет, броня, оружие, скилл, UI) проходит этот конвейер **до** попадания в `<img>`.

Почти все исходники — PNG 1024×1024 (~300 КБ). В ячейке инвентаря это 56px.
Браузер не должен качать мастер.

## Правило

| Слой | Что | Кто трогает |
| --- | --- | --- |
| Мастер | PNG (или большой кадр) рядом в `public/assets` | кладём файл |
| Рантайм | `.webp` того же имени, уменьшенный | `node scripts/assets/optimize.mjs` |
| Код | только `iconUrl(...)` / `getAvatarPath(...)` | никогда `.png` в `<img>` |

Пока мастера лежат в `public/` (уже в git). В UI они не запрашиваются.
Позже их можно вынести в `art_masters/` — рантайм от этого не меняется.

## Размеры сборки

| Путь | Сторона | Зачем |
| --- | --- | --- |
| `icons/characters/avatars/` | 384 | портрет героя |
| остальные `icons/` | 256 | слот 56px × retina, карточки |
| `art/` | до 1920 | полноэкранные сцены (обычно уже WebP) |

## Как добавить 800+ предметов

1. Положить мастер-PNG в `artifacts/my-app/public/assets/icons/…`
2. Запустить `node scripts/assets/optimize.mjs`
3. В данных предмета: `icon: iconUrl('weapons/bow/t07')`  
   (без расширения или с `.png` — функция всё равно отдаст `.webp`)

Повторный запуск пропускает свежие WebP. `--force` пересобирает всё.

Нужен ImageMagick `convert` (есть в Arena и на большинстве Linux).
