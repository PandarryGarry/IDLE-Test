## Агентский прогон (без Supabase)

Нужен dev на `http://127.0.0.1:3000` (не production-preview).

```bash
# один раз на песочницу, если нет /tmp/chromium:
node scripts/qa/setup-browser.mjs

# сервер (фоном, не одноразовый bash):
corepack pnpm --dir artifacts/my-app dev --host 127.0.0.1 --port 3000

corepack pnpm --dir artifacts/my-app typecheck
node scripts/qa/tour.mjs
```

Ожидание: **exit 0**, ~45–60 с. Кадры: `QA_OUT/tour/` (по умолчанию `/tmp/aethelia-qa-out/tour/`).
Запрещённый кадр: любой с текстом «Aethelia / Загрузка...».

Мок: `localhost` + `localStorage.aethelia_qa_mock_v1=1` (ставит `tour.mjs`).
Также DEV без `VITE_SUPABASE_URL`, либо сборка `VITE_QA_MOCK=1`.
В Replit с ключами мок **выключен**.

Учётка тура (только мок, не облако): email `qa.tour@aethelia.local`, герой `Каель`.

### Не ретраить

- `enableQaMock({reset})` на **каждый** `evaluateOnNewDocument` — стирает БД на reload Vite.
- Returning + `dropSession` + логин + `navigate('/rules')` → пустой `#root` ~20 с
  на коричневом splash. Returning держит сессию мока.
- Playwright / apt / `@sparticuz/chromium@149`. Канон: 131.0.1 + puppeteer-core 23.11.1.
- Менять `minDisplayTimeMs` (4000) и `SIGN_MIN_MS` без владельца.
