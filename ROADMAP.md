### ЭТАП 1: UI Foundation — Централизация компонентов
**Цель:** Создать единый файл gameUI.tsx со всеми переиспользуемыми примитивами.
Это фундамент — без него каждый экран будет "сборной солянкой".

**Что войдёт в gameUI.tsx:**
- `GButton` — кнопка (primary / secondary / danger / ghost)
- `GInput` — поле ввода (с иконкой, валидацией)
- `GModal` — модальное окно (с оверлеем, анимацией)
- `GCard` — базовая карточка (с вариантами)
- `GBadge` — значок (уровень, редкость, статус)
- `GAvatar` — аватар персонажа (круглый, с рамкой редкости)
- `GProgressBar` — полоса прогресса (XP, HP, Mana)
- `GDivider` — разделитель секций (с заголовком по центру)
- `GTooltip` — всплывающая подсказка
- `GPanel` — панель/блок (стандартный контейнер)

**Правило:** Ни один новый экран не создаётся без использования этих компонентов.

**Вопросы перед стартом:** нет, всё ясно.

### ЭТАП 7: Система предметов — "Пощупать предмет"
**Цель:** Каждый предмет — живой, ощутимый, с историей.

**Структура предмета (расширить items.ts):**
```ts
interface Item {
  id: string
  name: string              // "Дубовое бревно"
  description: string       // "Крепкое бревно из старого дуба..."
  lore: string              // Атмосферный текст
  category: ItemCategory
  rarity: Rarity
  weight: number            // "Вес" в инвентаре
  iconPath: string          // путь к нашей иконке
  stackable: boolean
  maxStack: number
  sellValue: number
  stats?: ItemStats         // для экипировки
  craftingInfo?: string     // откуда берётся
}
```

**Попап предмета:**
- Большая иконка слева (из наших PNG)
- Название + редкость (цветная рамка)
- Описание + лор-текст курсивом
- Характеристики (если есть)
- Кнопки: Экипировать / Использовать / Продать / Выбросить

**Привязка иконок:**
- Дерево → materials/wood/log_t01.png ... log_t12.png
- Руда → materials/metals/ore_t01.png ... ore_t12.png
- Рыба → materials/food/fish/fish_01_raw.png ...
- Оружие → weapons/sword_1h/t01.png ... t12.png
- Броня → armor/plate/t01/chest.png ...
