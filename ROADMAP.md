### ЭТАП 4: Создание персонажа
**Статус:** ✅ смёржено в `main`: PR #6 (герой, правила, выбор, 3-уровневые сейвы, cinematic onboarding) → PR #7 (кинематографическая дорога акты 0–7: ЗНАК → КОНТИНЕНТ → ТРАКТ → ГОРОД → ПОРОГ → ТАВЕРНА → ЛОЖА → ВЫХОД; фиксы iOS; план адаптива) → PR #8 (QA-фиксы дороги по live-вердикту владельца: стабильный арт путника, жёлтый кружок у кнопки, фраза возвращения «Знакомый скрип вывески.», таймауты против вечного «Загрузка...», надпись «ТОПОР И ПЕРО» на вывеске, акт 0 без размытой подложки; слой 1 адаптива с PoC на auth). Владелец тестирует всё в Replit ПОСЛЕ мержа PR #8.

**Решено:** Один персонаж на аккаунт, раса + аватар, ник = персонажу, без классов.

**Что нужно:**
1. Онбординг: заставка → короткий вход в таверну → регистрация (без «Имя») → правила → создание героя в ложе → выход в город → «Что нового» → игра.
2. **Выбор персонажа** — кинематографичный экран на фоне выхода в город: карточка аватар+ник+раса+общее время, кнопки и мягкий переход в игру.
3. **Создание персонажа** — двухступенчатый выбор: **раса (1 из 5)** → **6 аватаров этой расы** → **ник** (глобально уникален, RPC).
4. Раса = 5 (human/elf/dwarf/orc/beastfolk); бонусы расы — **структура «2+ / 1−»** (конкретика настраивается позже, на формулы не влияет).
5. Анимированный переход в игру после создания; «Что нового» — после онбординга.

**Данные (две таблицы — аккаунт и персонаж раздельно):**

`profiles` (аккаунт): `role` (`user|admin`), `rules_accepted_at`, `rules_version`,
`donate_currency` (донат-валюта НА АККАУНТЕ), `selected_character_id`.

`characters` (персонаж): `id`, `user_id` (FK→profiles.id), `nickname` (глобально уникален),
`avatar_id`, `race_id`, `save_data` (jsonb), `last_saved_at`, `created_at`,
`has_changed_nickname/avatar`, `is_deleted` + `deleted_at` (мягкое удаление, TTL 1 мес).

**Решено:**
- Никнейм и аватар — **на персонажа**; смена 1 раз бесплатно (в настройках), дальше — за донат-валюту.
- **Донат-валюта на аккаунте**, не на персонаже: при удалении персонажа не теряется.
- Создание нового перса **жёстко удаляет** старого (перс + инвентарь); защита — двойной confirm из Settings.
- Характеристики/профессии/скиллы — РАЗНЫЕ системы (полноценные — в следующие этапы; в Этап 4 только каркас+раса+время).
- Сейвы трёхуровневые: память → локальный (~30с) → облако (~3 мин + pagehide).
- **Melvor → Aethelia** — переименовать всё и сразу (без миграции ключа сейва).

**Проверить после реализации:**
- [x] `/register` → правила → создание персонажа (раса → аватары → ник) → игра
- [x] Возврат: выбор персонажа → «Что нового» → игра (Choice-экран показывается на каждом входе)
- [x] «Создать нового», удаление перса (двойной confirm), смена ника/аватара (1× бесплатно)
- [x] Guest: НЕ попадает в создание персонажа (играет в ограниченном шелле)
- [ ] Оффлайн: единственному персу, при холодном старте (облако vs локальный, ожидает тест)

**Файлы Этапа 4 (новые):**
`src/data/characters.ts` (расы/аватары/бонусы «2+/1−»), `src/data/rules.ts`,

**Структура предмета (расширить items.ts):**
```ts
interface Item {
  id: string
  name: string              // "Дубовое бревно"
  description: string       // "Крепкое бревно из старого дуба..."
  lore: string              // Атмосферный текст
  category: ItemCategory
  rarity: Rarity
  weight: number            // "Вес" в инвентаре
  iconPath: string          // iconUrl('weapons/bow/t07') — WebP, не PNG
  stackable: boolean
  maxStack: number
  sellValue: number
  stats?: ItemStats         // для экипировки
  craftingInfo?: string     // откуда берётся
}
```

1. **Перед каждым этапом** — уточняю детали у тебя

3. **Хардкод** — запрещён. Только токены и CSS-переменные
4. **Один шаг за раз** — не прыгаю вперёд
5. **Тестирование** — скриншот после каждого изменения
6. **Коммиты** — после каждого завершённого шага
