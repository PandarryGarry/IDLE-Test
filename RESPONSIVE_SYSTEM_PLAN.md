# План: централизация адаптива для всех устройств

> Статус: **решения владельца зафиксированы 2026-08-30, тайминг — после живой QA
> кинематографической дороги в Replit.** Ничего не внедрено — это план.
> Закон проекта: не переписывать смерженное, расширять поэтапно.

## Зачем

Хардкодить размеры интерфейса под каждый класс устройств вручную —
неизбежная ошибка и усталость: каждый новый экран = 3–5 ручных проходов
медиа-запросами. Нужна централизованная система: планшет, ПК, телефон,
любое разрешение, вертикально и горизонтально — корректно и точечно,
без ручной подгонки на каждый случай.

## Решения владельца

| Вопрос | Решение |
| --- | --- |
| Направление | **Слоёная система** (4 слоя, см. ниже), поэтапно |
| Эталонные кадры | **1440×900** (ландшафт) + **360×800** (портрет) |
| Ретрофит | Новые экраны (Stage 5) + **худшие старые по одному** (первый — auth), с видео до/после |
| Тайминг | Обсуждаем после живой QA владельцем всей дороги в Replit |

## Диагноз (аудит кода на момент решения)

Две вселенных UI, не делящие общую шкалу:

1. **Игровая оболочка** (Sidebar/TopNavBar/страницы) — Tailwind v4,
   адаптивные префиксы, брейкпоинты одной шкалы (640/768/1024),
   мост `@theme inline` в `src/index.css` уже есть. Боль: разбросанные
   произвольные значения (`md:ml-[240px]`, `max-w-[1400px]`).
2. **Кинематографические экраны** (auth, пролог, ложа, создание —
   index.css, ~3000 строк) — десктоп-first + **11 ручных медиа-запросов**
   (641–1023, ≤640, ≤760, ≤380, ≤360): перекрытия позиций карточек,
   `background-position` арта на каждый брейкпоинт (26.5% / 27% / 63% /
   32%…), абсолютные координаты декоративного света в rem.

## Четыре слоя системы

### Слой 1 — единая шкала токенов («живая типографика»)

Все размеры/шрифты/отступы — только из шкалы `:root`:
`--space-*`, `--text-*`, `--radius-*` и т.п., каждый токен —
`clamp(мин, текучее, макс)`. Сырой px — только хайрлайны (1px).
Медиа-запросы остаются только для **структуры** (колонки → стек,
абсолютная композиция → центр), никогда — для размеров.

### Слой 2 — два эталонных кадра

- **Ландшафт 1440×900** — ПК, планшет горизонтально, телефон
  горизонтально (с масштабом).
- **Портрет 360×800** — телефон; планшет вертикально получает ту же
  композицию с более широкими предохранителями панелей.
- Вёрстка один раз в эталонных координатах (rem); коэффициент
  масштаба — чистым CSS (clamp на font-size `:root`), без JS.
- **Предохранители (закон доступности):** текст никогда не уходит ниже
  читаемого минимума (~13–14px эквивалент); пользовательское масштабирование
  браузера не блокируется никогда; `prefers-reduced-motion` уже уважается.

### Слой 3 — точка фокуса арта

Каждый арт — носитель одного параметра `--art-focus: X% Y%`
(мы уже вычисляем источники света: ложа 35% 62%, выход 60% 45%).
Одна общая утилита строит и позиционирование, и размытую подложку
(урок акта 0: `contain` + blurred `cover`-заливка краёв). Убивает
таблицу `background-position` × брейкпоинтов.

### Слой 4 — QA-матрица как скрипт

`shot_responsive.mjs` (puppeteer-риг уже стоит в рабочем окружении):
любой экран × матрица вьюпортов → один контактный лист. Матрица:

| Класс | Вьюпорты |
| --- | --- |
| Телефон портрет | 320×568, 360×800 (эталон), 390×844, 430×932 |
| Телефон ландшафт | 568×320, 844×390 |
| Планшет портрет | 768×1024, 834×1194 |
| Планшет ландшафт | 1024×768, 1194×834 |
| Десктоп | 1280×800, 1440×900 (эталон), 1920×1080 |

Прогон перед каждым смотром владельца; «точечно всё настроить»
становится повторяемой проверкой, а не надеждой.

## Порядок внедрения

1. Слой 1 (шкала) + **proof-of-concept на auth** (у него 3 медиа-блока —
   самый замученный экран). Видео до/после, контактные листы — владельцу.
2. Вердикт владельца → если «да»: слои 2–3, ретрофит худших экранов
   по одному за коммит.
3. Новые экраны Stage 5 рождаются сразу в системе.
4. Кинематографическая дорога (акты 0–7) одобрена владельцем покадрово —
   **не трогается** без отдельного решения владельца (иначе пересъёмка
   всех актов).
5. Tailwind-вселенная подключается к общей шкале через существующий
   мост `@theme inline` — токены становятся общими для обоих миров.

## Законы

- Цвета — только токены (уже действует); размеры — только шкала (новое).
- Новые экраны — только на примитивах ui/.
- Ничего не переписывать с нуля; каждый ретрофит — отдельный коммит
  с видео до/после.
- Мерж — только после чистого `tsc --noEmit` и просмотра владельцем.
