# Иконки (рантайм)

994 файла. **В UI не ссылаться на `.png`.**

- Мастер: `*.png` (1024×1024, не грузить в браузер).
- Игра: соседний `*.webp` через `iconUrl('weapons/bow/t07')`.
- Сборка: `node scripts/assets/optimize.mjs`.

Полный закон: [`scripts/assets/README.md`](../../../../../scripts/assets/README.md).
