# Арты Aethelia и режимы «оживления»

Runtime-арты лежат в этой папке и отдаются по абсолютным путям. Их движение,
геометрия и источники света для заставки задаются в `src/shared/artRegistry.ts`.

| Файл | Назначение | Что происходит |
|---|---|---|
| `splash_wide.webp` / `splash_tall.webp` / `splash_square.webp` | Заставка | Вывеска на цепях: спокойное покачивание, мерцание света, пыль и виньетка. Вариант выбирается под пропорции экрана. |
| `emblem_pair.webp` | Логотип в шапке сайдбара (60px, на мобиле — в шапке меню) | Скрещённые топор и перо — в точности пара с одобренного загрузочного арта; прозрачный фон, мягкое свечение через `drop-shadow` в `Sidebar.tsx`. Статичный знак, без «оживления». |
| `intro_sign.webp` | Акт 0 «ЗНАК»: первый кадр игры для нового устройства (`FirstLaunchIntro.tsx`) | Полный арт вывески во весь экран (эмблема не обрезается, края закрывает размытая подложка). Свет разгорается как угли, титул «ЭТЕЛИЯ» из трекинга, золотая пыль, световой bloom-переход в пролог. |
| `prologue_continent_dawn.webp` | Пролог, биты 1–2 | Панорама континента Этелия на закате (утверждён владельцем 2026-08-29, v2). |
| `prologue_wanderer_road.webp` | Пролог, бит 3 | Путник со спины идёт по тракту к городу вдали. |
| `prologue_city_gates.webp` | Пролог, биты 4–5 + финал выхода | Вороний Брод: улица за воротами, тёплые окна, вывеска «Топора и Пера» вдали. |
| `auth_tavern_background.webp` | Вход / регистрация | Общая зала таверны; поверх — лёгкая прозрачная форма и ambient-эффекты. |
| `cutscene_tavern_entrance.webp` | Пролог, бит 6 «Толкни дверь» | Открытый вход в таверну: camera push, свет, пыль, короткий текст и пропуск. |
| `character_creation_lodge.webp` | Создание героя | Вид из обжитой ложи; правая тихая зона зарезервирована под двухшаговую форму. |
| `cutscene_character_departure.webp` | Выход в город / выбор героя | Вид из таверны в город; слева — спокойная зона для карточки героя, также используется выходной сценой. |

## Правила

- В репозитории хранятся только утверждённые runtime-файлы: промежуточные
  `review_*`-варианты не добавляются.
- Иконки предметов/героя — не эта папка, а `public/assets/icons/` + конвейер
  `scripts/assets/README.md` (`iconUrl()`, никогда сырой PNG 1024 в UI).
- Новые полноэкранные сцены должны быть WebP; широкая версия — минимум,
  отдельный tall-вариант добавляем, когда кроп на телефоне перестаёт держать
  композицию.
- Катсцена должна быть короткой, пропускаемой тапом/кликом и отключаться при
  `prefers-reduced-motion`.
- Для сцены с дверями используем отдельные слои/анимацию, а не рисуем
  физически неверно открытые створки в финальном статичном кадре.
