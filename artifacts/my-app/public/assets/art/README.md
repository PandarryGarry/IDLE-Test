# Арты и режимы «оживления»

Файлы отдаются по абсолютным путям; режим и геометрия задаются в
`src/shared/artRegistry.ts`.

| Файл          | Режим   | Что делает                                                              |
|---------------|---------|-------------------------------------------------------------------------|
| `splash.png`  | `sign`  | Вывеска на цепях: маятниковое покачивание, мерцание свечей, пыль, виньетка; резкий арт бесшовно растворяется в размытой копии фона |
| `reserved.png`| `sigil` | Рунный круг: надпись неподвижна, круг медленно вращается в круговой маске, пульс свечения, пыль |

Замена на свои файлы: просто переположите `splash.png` / `reserved.png`
(имена в реестре). Если у вашего арта другая геометрия круга — поправьте
`sigil: { cx, cy, r }` в `artRegistry.ts` (доли ширины/высоты картинки).

Универсальные режимы для будущих артов (авто-детект по альфе в `AnimatedArt mode="auto"`):
`scene` (иллюстрация: ken-burns + лучи + пыль) и `cutout` (силуэт: парение + свечение + блик).

Если файла нет — `SplashScreen` показывает векторный герб, ничего не ломается.
