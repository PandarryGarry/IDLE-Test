# _review — временные кадры для обсуждения

Папка нужна, чтобы владелец мог посмотреть картинки там, где он работает, —
в Replit и на GitHub. **В `main` она не должна попасть**: удаляем перед мержем.

Открыть в Replit (после `git checkout` ветки): файлы лежат в
`artifacts/my-app/public/_review/`, в вебвью они доступны по путям:

- `/_review/review-01-humans-avatar-vs-body.jpg`
- `/_review/review-02-race-dolls.jpg`
- `/_review/review-03-overlays.jpg`
- `/_review/gear-a-paperdoll.jpg`
- `/_review/gear-b-mmoframe.jpg`
- `/_review/gear-c-showcase.jpg`
