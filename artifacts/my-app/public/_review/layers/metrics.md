# Резка полных комплектов на слои

Три утверждённых кадра (ткань, кожа, латы «переодет 1») нарезаны на пять
слоёв: шлем, грудь, перчатки, штаны, сапоги.

## Зоны (доли высоты фигуры)

| слой | зона |
|---|---|
| шлем | выше шеи (y < 0.145) |
| перчатки | кисти: y 0.50…0.70, вне средней полосы x 0.15…0.85 |
| сапоги | ниже y 0.85 |
| штаны | y 0.50…0.85 в средней полосе x 0.16…0.84 |
| грудь | всё остальное — торс и руки целиком |

Грудь считается вычитанием: маска минус остальные четыре зоны. Поэтому
между слоями нет ни щелей, ни наложений по построению.

## Проверка: собираем слои обратно

Непокрашенные слои накладываются на базу и сравниваются с полным кадром.

| комплект | расхождение |
|---|---|
| ткань | 719 px = 3.2% площади фигуры |
| кожа | 888 px = 3.9% |
| латы | 676 px = 3.0% |

Остаток — сглаживание на границах зон, не дыры.

## Грабли

1. **`-compose minus` в ImageMagick считает ИСТОЧНИК минус ПРИЁМНИК**, а не
   наоборот. Из-за этого грудь сначала оказалась равна штанам.
2. После умножения на альфу маска перестаёт быть плоской бинарной — после
   каждого шага нужно `-alpha off -colorspace gray -threshold 50%`.
3. Площадь слоя мерить только с `-alpha extract`, иначе получается средний
   RGB, а не покрытие.
