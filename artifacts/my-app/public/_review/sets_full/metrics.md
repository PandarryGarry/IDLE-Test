# Полные комплекты (сначала целиком, потом режем на слои)

Один рендер на комплект: персонаж в полном наборе из пяти вещей
(шлем, грудь, перчатки, штаны, сапоги) по иконкам владельца t01.

## Почему так, а не по одной вещи

Отдельная генерация каждой вещи давала: полупрозрачный слой груди,
разъехавшиеся латы, тканевые штаны, не вяжущиеся с верхом. Вещи
генерировались порознь и не стыковались друг с другом.

Из одного кадра слои не могут разъехаться — координаты общие по построению.

## Совпадение с базой (правок не потребовалось)

| комплект | фигура | сдвиг верха / низа / центра | IoU силуэта |
|---|---|---|---|
| ткань | 548×940 @ (238,56) | −3 / +2 / 0 | 0.847 |
| кожа | 549×939 @ (238,56) | −3 / +1 / 0 | 0.923 |
| латы | 536×945 @ (244,53) | −6 / +4 / 0 | 0.855 |

База: 548×935 @ (238,59). Расхождение до 6 px — выравнивание не нужно,
слой из такого кадра садится на тело как есть.

## Чем занято тело (доля изменённых пикселей)

| комплект | голова | торс | ноги |
|---|---|---|---|
| ткань | 87% | 107% | 100% |
| кожа | 52% | 98% | 102% |
| латы | 90% | 113% | 113% |

Больше 100% — доспех выступает за силуэт (объём). Голова у кожи занята
на 52%: шлем закрывает верх, лицо открыто. У ткани капюшон, у лат
шлем занимает 90%.

## Дальше

После утверждения вида режем на слои по зонам: голова → шея, шея → пояс,
пояс → щиколотка, кисти, стопы. Где граница ляжет некрасиво — для этого
слота делаем кадр «комплект минус вещь» и вычитаем.
