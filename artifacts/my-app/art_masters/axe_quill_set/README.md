## Решение владельца по размещению

- Знак живёт ТОЛЬКО в шапке левого сайдбара (60px; на мобиле — в шапке drawer).
- Верхняя панель слева пуста: без лого, без «AetheliaRPG», без индикатора «Мир: Этелия».
- Свечение — мягкий ореол чуть больше знака (`drop-shadow 0 0 10px rgba(212,134,10,0.38)`).
- Фон вырезан полностью (в т.ч. внутри силуэта); кольцо не используется.

## Рецепт знака из `axe_quill_splash_blackbg.png`

```bash
# 1. Силуэт: рамка ~12–22 люмы + закрытие дыр + мягкий край
convert axe_quill_splash_blackbg.png -colorspace Gray -level 5%,9% \
  -morphology Close Disk:2 -blur 0x0.8 mask.png
# 2. Прозрачность: CopyOpacity (ИСТОЧНИК первым)
convert axe_quill_splash_blackbg.png mask.png -alpha off \
  -compose CopyOpacity -composite pair.png
# 3. Обрезка по bbox пары → квадрат ×1.14 → 900px → WebP q88
convert pair.png -crop 735x610+322+60 +repage -gravity center \
  -extent 838x838 -resize 900x900 axe_quill_pair_900.webp
```

## Уроки (не повторять)

- ИИ-редактирование может молча ПЕРЕРИСОВАТЬ знак, сохранив bbox: версия с
  `axe_quill_v5_logo.png` перевернула слой пера под топор. Источник для правок —
  только одобренные мастера; после каждого прохода — пиксельная сверка (MAE
  внутри силуэта + зона пересечения).
- `axe_quill_v5_logo.png` — старая доработка (пересаженное перо), для правок не использовать.
