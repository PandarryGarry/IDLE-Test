# Манекены (paper dolls)

## Канон

| | |
|---|---|
| холст | 256×256, прозрачный фон |
| фигура | высота **227 px**, верх на **y=14**, по горизонтали по центру |
| поза | фронтально, руки ~40° от корпуса, кисти не перекрывают бёдра |
| вид | весь манекен в цвет кожи аватара (не серый комбинезон), из одежды только бельё |

## Эталон

`human_male_01_source_1024.png` — исходник генерации (1024, белый фон).
Утверждён владельцем 2026-09-02 как эталон стиля; остальные тела ведём от него.

В рантайме: `public/assets/icons/characters/paper_dolls/bodies/human_male_01.png`
(мастер) → `.webp` собирает `node scripts/assets/optimize.mjs`.

## Почему старое в архиве

`_rejected/paper_dolls/` — тела и оверлеи, сгенерированные до эталона.
У них силуэт распадался на отдельные части: например, у `human_male_01_body`
торс 73×227 и две руки 51×85 висели отдельно, между рукой и телом была пустота.
Кроме того, тело было в сером комбинезоне вместо цвета кожи.
Удалять не стали — лежит как история.
