# art_masters — вечный архив исходников артов

Здесь хранятся **мастер-оригиналы** артов Aethelia (lossless). Папка не
попадает в сборку (не раздаётся как статики) и служит источником для
перегенерации runtime-WebP.

## Правило

Арты из этой папки **никогда не удаляются**, даже если перестают
использоваться в игре: отложенные ассеты пригодятся в будущем.

Исключение — прямые указания владельца: 29.08 по его запросу удалены
все отклонённые генерации и промежуточные скриншоты (векторы, сеты v2–v4,
макеты, листы выбора). Хранится только утверждённое.

## Решение владельца по знаку (29.08, финал)

- Знак «Топор и Перо» — **главный символ игры**; направления «руна» и
  «рунная буква А» отменены.
- В интерфейсе знак живёт **только в шапке левого сайдбара**: 60px,
  без золотой коробки, мягкое золотое свечение **под** знаком
  (радиальное, не квадрат).
- Топбар **полностью очищен слева**: убраны логотип, «Aethelia RPG»
  и индикатор «Мир: Этелия».
- На мобиле знак — в шапке выезжающего меню.

## Рецепт: runtime-эмблема из мастера (для вживления)

Ядро знака в `axe_quill_v5_logo.png`: bbox по порогу 35% =
`523x521+437+115` (центр кольца ≈ (698,375), радиус ≈ 261).

```bash
# 1) маска-диск (безопаснее заливки — не «течёт»)
convert -size 1408x768 xc:black -fill white \
  -draw "circle 698,375 698,103" -blur 0x1.5 mask_disk.png
# 2) альфа через CopyOpacity (порядок: ИСТОЧНИК, МАСКА!)
convert axe_quill_v5_logo.png mask_disk.png -alpha off \
  -compose CopyOpacity -composite emblem_alpha.png
# 3) bbox по альфе, кроп, квадрат с полями ×1.26, 900px, WebP
#    (позиционирование на холсте — только через -gravity center -extent,
#     -geometry +X+Y с -composite на прозрачном холсте в IM6 НЕ работает)
#    Итог: public/assets/art/intro_emblem.webp (900×900, альфа, ~53KB)
```
