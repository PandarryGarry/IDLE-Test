# art_masters — вечный архив исходников артов

Здесь хранятся **мастер-оригиналы** артов Aethelia (lossless). Папка не
попадает в сборку (не раздаётся как статики) и служит источником для
перегенерации runtime-WebP.

## Правило

Арты из этой папки **никогда не удаляются**, даже если перестают
использоваться в игре: отложенные ассеты пригодятся в будущем.

Исключение — прямые указания владельца: 29.08–30.08 по его запросу удалены
отклонённые генерации и устаревшие превью. Хранится только утверждённое.

## Решения владельца по знаку

- **Главный символ игры** — «Топор и Перо»; направления «руна» и «рунная
  буква А» отменены.
- **В интерфейсе** знак живёт только в шапке левого сайдбара: 60px, пара
  топор+перо (из арта 2) без кольца, прозрачный фон, мягкое свечение чуть
  больше знака. Топбар слева пуст. На мобиле — в шапке выезжающего меню.
- **Акт 0 «ЗНАК»** (утверждён 30.08 по видео-превью): первый кадр игры для
  нового устройства — полный арт 2 во весь экран (без обрезки эмблемы,
  края экрана закрывает размытая подложка того же арта), свет разгорается
  как угли, «ЭТЕЛИЯ» из разреженного трекинга, золотая пыль, световой
  bloom-переход в пролог. Рантайм: `public/assets/art/intro_sign.webp`.
