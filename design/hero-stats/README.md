# Лист характеристик героя — анализ и 4 варианта

**Статус:** B3 на «Пути» (дощечки + список снизу). Мокап SVG — только сетка.
**Экран:** вкладка «Путь» в хабе героя. «Тело», «Экип» и «Пульт» 3×N не пересобираются.
**Стиль:** палитра `index.css` (пергамент / дерево / каштан / золото). Без стекла и без Google Fonts.
**Числа на мокапах:** человек 1-го уровня, старт 4/3/2/1 — HP 176, Удар 14.4. Полосы опыта нет: кривая ещё не обсуждалась.

## Что делают похожие игры

Idle и мобильные MMO почти никогда не показывают «все 20 чисел одинаковым списком». Обычно три слоя:

1. **Тройка силы всегда на виду.** AFK Arena и Raid: HP / Attack / Defence крупно под портретом, остальное — по кнопке «i». [1](https://afk-arena.fandom.com/wiki/Heroes) [2](https://raidshadowlegends.fandom.com/wiki/Champion_Main_Window_GUI_Explained)
2. **Группировка, не каша.** Melvor держит боевые статы плотным списком с подписями слева и числом справа — одна рука, без портрета на листе. [3](https://wiki.melvoridle.com/w/Beginners_Guide)
3. **Портрет продаёт героя, не статы.** В AFK портрет занимает центр, статы — узкая нижняя кромка. У нас портрет уже в шапке хаба, второй полноростовой манекен уже есть во «Экипе».
4. **Уровень на основном HUD спорный.** В ARPG его часто прячут: он не равен силе. [4](https://www.reddit.com/r/LastEpoch/comments/1aokb7h/character_level_ui/) На листе персонажа уровень нужен; полосу XP сюда не ставим, пока нет кривой.

Для наших 4 столпов × 3 подхарактеристики это значит: либо 4 карточки системы, либо тройка «живучесть / урон / защита» плюс остальное, либо плотный лист.

## Четыре варианта

| | Идея | Откуда | Плюс | Минус |
|---|---|---|---|---|
| **A** | 2×2 карточки столпов | TFT / бенто, но в дереве | Вся система на одном кадре, тап по карточке = столп | На 320px тесновато |
| **B** | Портрет + тройка HP/Удар/Броня + список | AFK Arena, Raid | Привычный «чемпион» | Портрет дублирует шапку и Экип; на мокапе низ списка с галлюцинациями подписей |
| **C** | Вертикальные секции-строки | Melvor, Albion-списки | Лучшая читаемость 12 чисел одной рукой | Меньше «витрины» |
| **D** | 4 крупных числа + сетка вторичных | WoW / Last Epoch dashboard | Сила считывается за секунду | Столпы как система уходят на второй план |

Мокапы: `variant-A.png` … `variant-D.png`. Это концепты композиции, не пиксель-перфект вёрстка.

**Рекомендация агента: A**, запасной **C**. A продолжает язык столпов (как шапка «Нитей»). C — если важнее таблица, чем карточки.

## Выбор владельца (2026-09-05)

База **B**, доработка **B3**. Реализовано во вкладке «Путь»:

- шесть дощечек, **3 в ряд**: Здоровье · Удар (диапазон) · Броня / Уворот · Крит · Удача;
- **под ними** остальные 7 подхарактеристик пачками столпов (столп — разделитель);
- без второго портрета и без сброса на листе;
- полоса **опыт** в шапке хаба (на всех вкладках);
- сброс только в настройках персонажа.

Диапазон удара: ±15% от Удара (`balance/strikeRange.ts`), растёт с героем. В бой не входит. Крит 5% — заглушка. Полоса опыта читает `heroXp / xpToNextLevel`.
